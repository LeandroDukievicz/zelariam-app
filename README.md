# Zelariam Landing Page

Landing page em Astro para apresentar o Zelariam, um aplicativo de cuidado familiar para idosos.

## Sobre

A página destaca os principais benefícios do produto:

- organização de medicamentos, doses e horários;
- rotina diária compartilhada entre família e cuidadores;
- acompanhamento de sinais vitais e ocorrências;
- modos de uso para idoso, cuidador e família;
- acesso antecipado para pessoas interessadas no aplicativo.

## Tecnologias

- Astro
- CSS nativo
- Assets estáticos em `public/`

## Como rodar localmente

```bash
npm install
npm run dev
```

O projeto ficará disponível, por padrão, em `http://localhost:4321/`.

## Build de produção

```bash
npm run build
```

Os arquivos estáticos são gerados em `dist/`.
